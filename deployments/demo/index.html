Демо-клиент OAuth 2.1

Одна страница, которая проходит весь цикл: PKCE → /oauth/authorize → вход → согласие → обмен кода → работа с токенами через Nginx.

Этот адрес не считается «secure context»: crypto.subtle недоступен, PKCE не сможет посчитать S256. Откройте страницу через http://localhost:8088/demo/.

1. Параметры клиента

Демо-клиент — публичный (PKCE, без секрета) и зарегистрирован с require_consent = true, поэтому экран согласия виден всегда.

2. Токены

Токенов пока нет — нажмите «Войти через IAM».

«Повторить старый refresh» в первые 10 секунд вернёт ту же пару (идемпотентный ретрай), а позже приведёт к invalid_grant и отзыву всей цепочки — после этого и ранее выданный access-токен перестанет проходить /verify.

3. Ответ API

Здесь появится ответ защищённого endpoint-а вместе с заголовками, которые добавил Nginx.

4. Журнал запросов

Инструмент для локальной отладки. Не публикуйте его в production: страница показывает токены в открытом виде.
